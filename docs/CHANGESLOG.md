# 変更履歴 (CHANGELOG)

このファイルには、版ごとの主な変更を新しい順に記録します。書式は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) を参考にしています。

版番号は変更を整理するための呼び名です。コード内には記録していません。

## [1.5] - 2026-10-25

### 追加
- 班なしタスク(どのチームにも属さない単発タスク)を、全員が作成できるようにしました。
- タスク詳細の「取り組む」ボタン。押した人がそのタスクの担当者になります(1タスク1人)。
- 「取り組みをやめる」ボタン。担当者本人と会長・システム管理者が行えます。
- ホームに「班なしタスク」のカード、班別一覧に「班なし」タブ、タイムラインに「班なし」のグループを追加しました。
- 取り組みを「担当者」シートと「操作ログ」に記録するようにしました(将来のポイント機能の土台。ポイント機能そのものは未実装です)。

### 変更
- 班なしタスクのアーカイブ/元に戻すは、作成者と会長・システム管理者ができるようにしました。

### 注意
- シートの列は増えていないため、`setup` の再実行は不要です。

## [1.4] - 2026-10-23

### 追加
- 班別一覧からプロジェクトを追加できるようにしました。
- 保存・削除などの操作中に「実行中…」を表示し、画面の操作を止めて二重押しを防ぐようにしました。

### 変更
- タスクとプロジェクトを、登録メンバー全員が全チームに作成・編集できるようにしました。

### 削除
- 「副会長」の役職を廃止しました。「全体権限」シートに残っている「副会長」の行は無視されます。

## [1.3] - 2026-10-23

### 追加
- チームのアーカイブを追加しました。アーカイブ後も、資料の追加と削除はできます。
- 資料ページに検索を追加しました。資料名・URL・追加者・チーム名・プロジェクト名・タスク名を対象にします。
- 「班」シートに `アーカイブ` 列を追加しました。

### 変更
- チームリーダーが、自チームのメンバーを自由に追加・削除できるようにしました。リーダーの任命・解任は、管理者だけが行えます。

### 注意
- `setup` の再実行が必要です(`アーカイブ` 列を追加するため)。

## [1.2] - 2026-10-22

### 追加
- 資料の削除機能を追加しました。「削除」ボタンを2回押すと実行されます。
- ホームでライト / ダークの表示を切り替えられるようにしました(ブラウザに記憶されます)。
- 開始日・期限に、時刻を指定できる選択肢を追加しました。
- タスクとプロジェクトを新規作成するときに、資料も一緒に登録できるようにしました。

### 変更
- 資料の追加・削除を、区分を問わず全員ができるようにしました。
- タスクとプロジェクトを、所属チームのメンバーも作成・編集できるようにしました(説明欄を含む)。
- 資料リンクと見出しの色を区別しました(リンクは青の下線、見出しは黒の太字)。
- 資料ページを、クリックで開閉するプルダウン形式にしました。
- タイムラインの絞り込みを、プロジェクトごとからチームごとに変えました。

## [1.1] - 2026-10-22

### 追加
- 資料を4区分(タスク / プロジェクト / チーム全体 / 全体)で登録できるようにしました。
- 資料ページからも資料を追加できるようにしました。
- 「資料リンク」シートに `区分` と `対象ID` 列を追加しました。

### 注意
- `setup` の再実行が必要です(`区分` と `対象ID` 列を追加するため)。

## [1.0.1] - 2026-10-22

### 修正
- 画面が「読み込み中…」のまま止まる不具合を直しました。HTMLの文字参照をスクリプトに直接書かない形に変更しました。

## [1.0] - 2026-10-22

### 追加
- 第1版(MVP)を公開しました。
- ホーム、チーム別一覧、プロジェクト、タイムライン、自分のタスク、資料、管理、会議モードを実装しました。
- 権限の確認をサーバー側で行うようにしました。
- すべての更新を「操作ログ」シートに記録するようにしました。
